# 課題テーマ案と開発メモ

## 仮題

画像で試料IDを認識する材料分析向け自動搬送ロボット

## 目的

材料開発では調製済み試料を複数の分析工程へ受け渡す必要がある。本作品は、識別情報を読み取り、搬送先を選び、ロボットで密閉キャリアを受付位置へ移す工程の試作である。現時点のトレイは分析装置の受付を表す抽象モデルであり、実在装置のローディング機構は再現していない。

## 最初に実現した範囲

- CRANE+ V2のモデルを使ったCPU物理シミュレーション。
- ヘッドレス描画とMP4生成。
- GPUで小型画像認識CNNを学習。
- IDの置き場所を入れ替えても、画像のID判定に対応したトレイへ搬送。
- 簡易把持・既知の試料座標を使う初期ベースライン。

## 次の開発項目

1. まず作品の用途を具体化する。例：分析予約リストに従う密閉済み材料試料の受渡し。
2. ID・搬送先・優先順位をCSVで与え、試料履歴と結果をログへ残す。
3. 位置の固定配置依存を減らし、画像からの位置推定と到達可能性判定を追加する。
4. 接触モデルと指の動作を調整し、weldを使わない摩擦把持を別条件で検証する。
5. 見つからないID・低信頼度・到達不能・搬送失敗では停止して理由を表示する。
6. 成功率、誤配送率、位置ずれ、処理時間を、条件を揃えて比較する。
7. 最終仕様に合わせて1〜3分の動画とPDFレポートを作成する。

## 評価の区別

- マーカー画像の識別精度と搬送成功率を分けて報告する。
- 模擬画像のみの学習・評価であることを明記する。
- 簡易把持の成績を実機や摩擦把持の成功率として扱わない。
- 環境構築やコード生成にAIを使うだけでなく、実行中にもCNNの出力を搬送判断に使用する。
